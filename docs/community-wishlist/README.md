# Malolos Community Wishlist

The Community Wishlist is an independent, resident-led BetterMalolos feature for constructive ideas about improving Malolos. It is separate from [`/ideas/`](../../ideas/), which remains the channel for BetterMalolos product feedback, sources, and volunteer offers.

The current public page is a read-only prototype at [`/community-wishlist/`](../../community-wishlist/). Public submissions and support must not be enabled until the launch checklist below is complete and reviewed. The engineering launch register is [`launch-gate.md`](launch-gate.md); it contains no private names, credentials, or infrastructure secrets.

## Phase 0 launch checklist

- [ ] Confirm the platform owner, primary moderator, backup moderator, escalation contact, and 48-business-hour review target.
- [ ] Obtain Philippine legal/privacy review of the privacy notice, terms, moderation rules, retention schedule, and incident process.
- [ ] Complete a non-binding orientation with relevant City/barangay offices and record only verifiable outcomes.
- [ ] Publish the methodology and status lifecycle.
- [ ] Configure the private operational inbox and SMTP values only in Hostinger environment variables.
- [ ] Complete the MariaDB backup, quota, disposable-copy migration, and deployed-revision checks before Phase 2.

The first five items are governance and privacy gates. The last item is an
infrastructure readiness gate. Until the open items have named owners and
verifiable evidence in the private operations record, the public prototype is
the only enabled Wishlist surface.

## Principles

Ideas, not attacks. Improvements, not accusations. The Wishlist never implies City endorsement, authority, funding, approval, partnership, or response without a verifiable source.
